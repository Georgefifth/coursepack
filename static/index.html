Import from Canvas

  1. Open your course and go to Settings.
  2. Choose Export Course Content, then the Course export type.
  3. Download the .imscc or .zip and import it here.

CoursePack reads packages with imsmanifest.xml. Offline HTML packages generated from Modules are not supported.

Quizzes, external tools, and unsupported content are marked explicitly. Uploads stay in local server memory until cleared, expired, evicted, or the service stops. Up to three course sessions are retained for two hours.

This tab stores course and module names, order, and selections for same-package reimport. It does not store course files or body content. Clear course also removes the arrangement draft.

The demo is synthetic and includes an intentionally missing image and an external link to demonstrate review.
