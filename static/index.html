从 Canvas 导入课程

  1. 打开课程，进入「设置」。
  2. 选择「导出课程内容」，导出类型选「课程」。
  3. 下载完成后，把 .imscc 或 .zip 文件导入这里。

首版读取带有 imsmanifest.xml 的课程包。Modules 中生成的离线 HTML 包暂不支持。

测验、外部工具和不支持的内容会明确标记。上传文件留在本机内存，清除课程或停止服务后释放；最多保留三个课程会话，两小时后过期。

本标签页会暂存课程和模块名称、顺序及勾选状态，用于重新导入相同课程包后恢复；不暂存课程文件或正文。清除课程也会清除整理进度。

示例课程为合成材料，包含故意缺失的图片和外部链接，便于试用检查流程。
